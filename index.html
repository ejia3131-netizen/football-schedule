确认记录保存在你的 GitHub 仓库，所有设备都会同步。每台设备只需要设置一次。

  1. 打开 GitHub 新建 Fine-grained token
  2. Repository access 选 Only select repositories → football-schedule
  3. Permissions → Repository permissions → Contents 选 Read and write
  4. 生成后复制 token，贴到下面

赛程来自 Flashscore，只包括英超、英格兰联赛杯（EFL Cup）、欧冠、欧联、马来西亚所有联赛，以及有马来西亚球队参加的比赛。信号源状态来自 PandaScore，网站一般只在开赛前几小时才列出比赛，所以较晚的比赛会先显示「未列出」。推流链接带签名，大约 24 小时后失效，赛程每 10 分钟自动刷新，每次显示今天起 7 天内的比赛。时间按你设备的时区显示。
